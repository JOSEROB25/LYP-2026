# Imagenes de codigo EmojiLang

Guarda aqui fotografias o capturas de programas escritos con emojis.

## Flujo recomendado

1. Guarda la imagen en esta carpeta.
2. Adjuntala en el chat con la IA.
3. Pidele que transcriba los emojis respetando los saltos de linea.
4. Guarda el resultado como un archivo `.emoji` dentro de `programas`.
5. Ejecutalo con `ejecutar_nombre_apellido.bat` o desde VS Code.

La IA puede leer directamente una imagen adjunta. El interprete local de Python no hace OCR automaticamente; para automatizar ese paso habria que instalar y configurar una herramienta OCR.

## Recomendaciones para las fotos

- Usa buena luz y evita reflejos.
- Fotografia el codigo de frente.
- Incluye todos los emojis completos, especialmente los que llevan variacion como `✖️`, `⬆️` y `🖨️`.
- No cortes la primera ni la ultima linea.
